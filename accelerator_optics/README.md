# Магнитная оптика ускорителя

Серия коротких анимаций о магнитных элементах ускорителя.

1. Дипольный магнит: положительная частица проходит через сектор с однородным
   поперечным полем, поворачивает на 90 градусов и выходит без изменения
   модуля импульса.
2. Квадрупольный магнит: поле растёт линейно с расстоянием от оси, фокусируя
   пучок в одной поперечной плоскости и расфокусируя в другой.
3. Секступольный магнит: поле растёт квадратично с расстоянием от оси и в
   области ненулевой дисперсии исправляет импульсную зависимость фокусировки.
4. Накопительное кольцо: сначала по шагам показываются дипольный поворот,
   фокусировка чередующимися квадруполями и совместная работа квадруполя с
   секступолем. Затем один и тот же спектр частиц сравнивается без
   секступольной коррекции и с ней.

В ролике о диполе оставлена одна основная формула. Постоянная длина стрелки
импульса показывает, что магнит меняет направление, но не энергию частицы.
Уравнение силы Лоренца связывает направление движения, магнитное поле и
поперечную силу. Отдельные цветовые стрелки показывают скорость с импульсом и
силу Лоренца; кружки с точкой обозначают однородное поле, направленное к
наблюдателю.

## Рендер

Быстрый вертикальный просмотр:

```bash
cd accelerator_optics
DVN_PROFILE=shorts DVN_FRAME_RATE=15 manim -ql magnetic_optics.py DipoleMagnetScene
```

Финальный вертикальный ролик 1080×1920, 60 кадров/с:

```bash
./render.sh
```

Квадруполь:

```bash
DVN_PROFILE=shorts DVN_FRAME_RATE=15 manim -ql quadrupole_optics.py QuadrupoleMagnetScene
./render_quadrupole.sh
```

Секступоль:

```bash
DVN_PROFILE=shorts DVN_FRAME_RATE=15 manim -ql sextupole_optics.py SextupoleMagnetScene
./render_sextupole.sh
```

Кольцо:

```bash
DVN_PROFILE=shorts DVN_FRAME_RATE=15 manim -ql ring_optics.py StorageRingScene
./render_ring.sh
```

Горизонтальная версия 1920×1080:

```bash
DVN_PROFILE=widescreen ./render.sh
```

Основные цвета и длительности находятся в `run.cfg`. Геометрия дипольной
траектории вынесена в `trajectory.py`, поле и лучевая модель квадруполя — в
`quadrupole.py`, а хроматическая модель секступоля — в `sextupole.py`. Модели
кольца и симплектический трекинг находятся в `ring_model.py`. Все модели
проверяются командой

```bash
python -m unittest discover accelerator_optics/tests -v
```

## Публикация в галерее

Тяжёлые файлы из `media/` не входят в Git. После утверждения ролика в
`neutrinohit-map/animations.catalog.json` добавляется элемент с каталогом
`accelerator_optics` и путём к итоговому MP4. Затем из `neutrinohit-map`
запускается

```bash
python scripts/sync_dvnanima_gallery.py
```

Скрипт создаёт облегчённую web-версию H.264, постер и заново генерирует
русскую страницу галереи. Сам сайт публикуется GitHub Actions после push в
ветку `main` репозитория `neutrinohit-map`.
