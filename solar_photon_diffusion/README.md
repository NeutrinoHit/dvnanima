# Диффузия света в Солнце

Минутная вертикальная Manim-анимация на русском и английском языках и отдельный
численный модуль для оценки времени
выхода излучения из Солнца. Сцена не рисует гигантский выдуманный «шаг
фотона»: микроскопический случайный ход явно помечен как увеличение, а движение
по всему радиусу показывает накопление среднего времени, вычисленное из
солнечного профиля.

Во время радиального прохода компактный график показывает локальный шаг
$\ell(r)=1/[\kappa_R(r)\rho(r)]$ в логарифмической шкале. Курсор графика,
диффузионный ореол, радиус и счётчик времени управляются одной переменной.
Цвет ореола кодирует локальную температуру $T(r)$ по логарифмической шкале;
легенда прямо отмечает, что это условный код температуры, а не наблюдаемый
цвет индивидуального фотона. После границы конвективной зоны счётчик явно
помечен как условное продолжение чистой диффузии: реальный внешний перенос
идёт преимущественно конвекцией и этой моделью не вычисляется.

## Результат модели

Для стандартной солнечной модели D. B. Guenther (2010):

- из центра до основания конвективной зоны: **31 572 лет**;
- из центра до фотосферы в чисто радиационной модели: **41 399 лет**;
- до фотосферы с усреднением по месту рождения энергии: **36 112 лет**;
- средний свободный пробег в центре: **0,0514 мм**.

Физический вывод и ограничения подробно описаны в [PHYSICS.md](PHYSICS.md).

## Проверка расчёта

Из корня `dvnanima`:

```bash
python -m solar_photon_diffusion.physics
python -m unittest solar_photon_diffusion.tests.test_physics -v
```

Компактная таблица в `data/solar_model_2010_grey_profile.csv` содержит 1455
оболочек до фотосферы. Её можно заново получить из исходной таблицы:

```bash
python solar_photon_diffusion/prepare_solar_profile.py
```

Скрипт скачивает только явно указанную в `PHYSICS.md` таблицу Guenther и
оставляет восемь нужных расчёту столбцов.

## Рендер

```bash
bash solar_photon_diffusion/render_preview.sh ru
bash solar_photon_diffusion/render_preview.sh en
bash solar_photon_diffusion/render.sh all
```

Основная сцена — `SolarPhotonDiffusion`; статичная обложка —
`SolarPhotonDiffusionStill`. Размер кадра 1080×1920, 30 fps; цвета и длительности
задаются в `run.cfg`. Полные файлы называются
`solar_photon_diffusion_ru.mp4` и `solar_photon_diffusion_en.mp4`.

## Музыка

Промпт для инструментального трека SUNO находится в
[`SUNO_PROMPT.md`](SUNO_PROMPT.md). После скачивания трека положите его в
`music/suno_solar_diffusion.mp3` и выполните:

```bash
bash solar_photon_diffusion/mix_music.sh \
  music/suno_solar_diffusion.mp3
```

Скрипт обрезает или зацикливает музыку до длительности ролика, нормализует её,
добавляет плавные вход и выход и собирает музыкальные RU/EN версии без
повторного кодирования изображения.
