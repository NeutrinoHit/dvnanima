# BBN Manim Animation

Стилизованная Manim Community Edition анимация первичного нуклеосинтеза для научпоп-лекции.

Сцена не моделирует реальные сечения реакций и не рассчитывает BBN численно. Это управляемая визуальная история: частицы слегка движутся и отражаются от границ, а ключевые реакции запускаются заранее выбранными парами.

## Запуск

Из этой папки:

```bash
manim -pqh bbn_manim.py BBNAnimation
```

Для быстрого предпросмотра без открытия плеера:

```bash
manim -ql bbn_manim.py BBNAnimation
```

## Содержимое

- `bbn_manim.py` — основная сцена `BBNAnimation`.
- `media/` — стандартный каталог вывода Manim.

В начале `bbn_manim.py` заданы константы:

```python
N_PROTONS = 18
N_NEUTRONS = 3
N_PHOTONS = 12
SEED = 7
```

## Сюжет

1. Горячая стадия: `p + n -> D`, затем фотон разбивает дейтерий.
2. Остывание: температура падает, фотонные лучи становятся длиннее и спокойнее.
3. Окно BBN: дейтерий выживает и ведёт к устойчивому `He-4`.
4. Финал: много свободных протонов, несколько стабильных `He-4`, состав `H ≈ 75%`, `He-4 ≈ 25%`, следы `D`, `He-3`, `Li-7`.
